# Frontend — Sistema Notebook Ometto

Aplicação web do sistema de solicitação, entrega e devolução de notebooks da E.E. José Ometto.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios

## Execução local

Crie o arquivo `.env` a partir do exemplo:

```bash
copy .env.example .env
```

Instale as dependências e inicie o projeto:

```bash
npm install
npm run dev
```

## Validação

```bash
npm run build
npm run lint
```
